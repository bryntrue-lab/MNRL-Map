## Step 2 — Install SVG support if not already present

If the project doesn't already render SVGs, install:

```bash
npx expo install react-native-svg react-native-svg-transformer
```

And configure `metro.config.js` to handle SVG imports as components. If `react-native-svg-transformer` setup is too complex, an alternative is to render the SVG inline using `react-native-svg` directly (see Step 3 alternative below).

**Composition.** Vertically centered in the screen — the eye lands on the wordmark first, with breathing room above and below. No bottom-heavy stacking.

- Alignment: centered under the wordmark
