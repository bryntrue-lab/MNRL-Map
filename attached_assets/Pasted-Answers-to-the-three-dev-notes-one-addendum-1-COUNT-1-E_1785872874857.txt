2. OVERLAP RULE EXTENSION — canonical, replaces bare subsumption:

   First, strengthen subsumption's guard: drop item A when A is a
   sub-sequence of B AND noteSet(A) == noteSet(B). Note-set equality, not
   count equality — coincidentally equal counts from different notes must
   not suppress. This also applies ACROSS classes: a WORD whose note set
   equals a phrase's that contains it is suppressed from display
   ("important · twice" disappears into the phrase; the word stays counted
   internally so it can resurface if its count later diverges).

   Second, MERGE overlapping siblings: when two grams have identical note
   sets and their token spans overlap in every contributing note, replace
   them with the union run (the full common word-sequence, allowed to
   exceed the 6-word window; cap merged phrases at 12 words). This is what
   subsumption can't reach — "this work is important to me" +
   "work is important to me and" merge because the true common run
   ("this work is important to me and") is 7 words, longer than the
   extraction window.

   Third, DISPLAY TRIM: strip TRAILING stopwords from a merged item's
   rendered form (never leading, never interior — leading stopwords like
   "this" are how people talk; a trailing "and" is a dangle). The stored
   key keeps the untrimmed run. Result for the founder's field: ONE
   gathering row — "this work is important to me" · twice.
